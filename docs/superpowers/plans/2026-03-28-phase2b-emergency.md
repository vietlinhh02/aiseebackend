# Phase 2b: Emergency & Escalation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 2 emergency/escalation agent tools (`emergency_alert`, `escalate_to_family`) with SOS broadcast push, GPS via data channel, and 30s timeout polling for family member answer.

**Architecture:** One new Go package (`internal/emergency/`) with Alert (broadcast push to all family) and Escalate (try one contact with 30s ListParticipants polling). LiveKit client gets `ListParticipants`. Agent worker gets `get_location` data channel action and `tool_call_with_timeout` on BackendClient. DataChannelBridge fixed to return full ACK payload.

**Tech Stack:** Go 1.26+, pgx/v5, sqlc, chi, livekit server-sdk-go, Python 3.12+, livekit-agents, httpx

**Spec:** `docs/superpowers/specs/2026-03-28-phase2b-emergency-design.md`

```sql
-- name: GetFamilyMembersOrdered :many
SELECT u.id, u.google_id, u.email, u.display_name, u.role,
       u.is_volunteer, u.avatar_url, u.fcm_token, u.apns_token,
       u.apns_voip_token, u.settings, u.created_at, u.updated_at,
       fl.relationship, fl.is_primary_contact
FROM users u
JOIN family_links fl ON (
    (fl.family_id = u.id AND fl.user_id = $1)
    OR
    (fl.user_id = u.id AND fl.family_id = $1)
)
WHERE fl.deleted_at IS NULL AND u.id != $1
ORDER BY fl.is_primary_contact DESC, fl.created_at ASC;
```

- [ ] **Step 2: Create `internal/emergency/service.go`**

Key design points:
- Service struct: `queries *dbgen.Queries`, `pusher *push.Pusher`, `lk *livekit.Client`, `lastAlert sync.Map`
- `NewService(queries, pusher, lk)` constructor
- **IMPORTANT:** All methods receive `userID string` but sqlc queries require `pgtype.UUID`. Always convert via `pgutil.ParsePgUUID(userID)` before calling any query method (`GetUserByID`, `GetFamilyMembersOrdered`).
- `Alert(ctx, userID, lat, lng float64) (AlertResult, error)`:
  1. Convert `userID` to `pgtype.UUID` via `pgutil.ParsePgUUID`
  2. Deduplication: check `lastAlert[userID]`, if <60s ago return error
  3. Get user via `queries.GetUserByID(ctx, uid)`
  4. Get family via `queries.GetFamilyMembersOrdered(ctx, uid)`
  5. Create room `"sos-" + short UUID` (use `uuid.New().String()[:8]`)
  6. Create LiveKit room via `lk.CreateRoomWithTimeout(ctx, roomName, 300)` — 5 min auto-cleanup
  7. Generate token via `lk.CreateToken`
  8. Send VoIP push to ALL family members — build `push.UserTokens` from each row's FcmToken/ApnsToken/ApnsVoipToken. Convert lat/lng to string via `fmt.Sprintf("%.6f", lat)`
  9. Store `lastAlert[userID] = time.Now()`
  10. Return AlertResult
- `Escalate(ctx, userID, contactName string, skip []string) (EscalateResult, error)`:
  1. Convert `userID` to `pgtype.UUID` via `pgutil.ParsePgUUID`
  2. Get user via `GetUserByID` for display name
  3. Get family via `GetFamilyMembersOrdered`
  4. If contactName: filter by Vietnamese-normalized substring match on DisplayName/Relationship
  5. If skip: remove matches by normalized DisplayName
  6. If empty: return `{Status: "no_contacts"}`
  7. Take first, collect remaining names
  8. Create room `"esc-" + short UUID`
  9. Create LiveKit room via `lk.CreateRoom`, generate token
  10. Send VoIP push to the one contact
  11. Poll loop with `select` on `ctx.Done()`, `deadline` (30s), `ticker` (5s):
      - On tick: `lk.ListParticipants` → if any participant with identity != userID → return answered
      - On deadline: `lk.DeleteRoom`, return no_answer
      - On ctx.Done: `lk.DeleteRoom`, return no_answer with ctx.Err()

Vietnamese normalization: copy the `normalizeVN` function from `internal/medication/service.go` (same pattern). This is the third copy in the codebase — after Phase 2b, consider extracting to `pkg/textutil/` but not now.

```go
func (h *Handler) handleEmergencyAlert(
	ctx context.Context, req ToolCallRequest,
) (any, error) {
	lat, _ := req.Params["lat"].(float64)
	lng, _ := req.Params["lng"].(float64)

	result, err := h.emergency.Alert(ctx, req.UserID, lat, lng)
	if err != nil {
		return nil, err
	}

	return map[string]any{
		"status":          "alert_sent",
		"room_name":       result.RoomName,
		"token":           result.Token,
		"family_notified": result.FamilyNotified,
		"location": map[string]float64{
			"lat": result.Lat,
			"lng": result.Lng,
		},
	}, nil
}

func (h *Handler) handleEscalateToFamily(
	ctx context.Context, req ToolCallRequest,
) (any, error) {
	contactName, _ := req.Params["contact_name"].(string)

	var skip []string
	if rawSkip, ok := req.Params["skip"].([]any); ok {
		for _, s := range rawSkip {
			if name, ok := s.(string); ok {
				skip = append(skip, name)
			}
		}
	}

	result, err := h.emergency.Escalate(
		ctx, req.UserID, contactName, skip,
	)
	if err != nil {
		return nil, err
	}

	resp := map[string]any{
		"status": result.Status,
	}
	switch result.Status {
	case "answered":
		resp["room_name"] = result.RoomName
		resp["token"] = result.Token
		resp["contact_name"] = result.ContactName
	case "no_answer":
		resp["tried"] = result.ContactName
		resp["remaining"] = result.Remaining
	case "no_contacts":
		// status only
	}
	return resp, nil
}
```

```python
    async def tool_call_with_timeout(
        self,
        tool: str,
        user_id: str,
        params: dict,
        timeout: float = 35.0,
    ) -> dict:
        """Send a tool call with custom timeout (for long-running tools)."""
        resp = await self.client.post(
            "/tool-call",
            json={"tool": tool, "user_id": user_id, "params": params},
            headers={"X-Internal-Key": self.api_key},
            timeout=timeout,
        )
        resp.raise_for_status()
        return resp.json()
```

```python
@function_tool()
async def emergency_alert() -> dict:
    """SOS khan cap — gui thong bao den tat ca nguoi than kem vi tri GPS."""
    try:
        location = await _bridge.send_action(
            _local_participant, "get_location", {},
        )
        lat = location.get("lat", 0)
        lng = location.get("lng", 0)
    except DataChannelTimeoutError:
        logger.warning("get_location timed out, using unknown location")
        lat, lng = 0, 0
    return await _backend.tool_call_with_timeout(
        "emergency_alert",
        _user_id,
        {"lat": lat, "lng": lng},
        timeout=20.0,
    )


@function_tool()
async def escalate_to_family(
    contact_name: str = "",
    skip: list[str] | None = None,
) -> dict:
    """Goi nguoi than ho tro khi AI khong giup duoc. Neu khong ai tra loi, goi lai voi skip de thu nguoi khac."""
    params: dict = {}
    if contact_name:
        params["contact_name"] = contact_name
    if skip:
        params["skip"] = skip
    return await _backend.tool_call_with_timeout(
        "escalate_to_family",
        _user_id,
        params,
        timeout=40.0,
    )
```
